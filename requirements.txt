# see artifacts/run_summary.json["versions"]), with one exception: XGBoost is

# same project, same import name (import xgboost), no CUDA dependency.
#
# Python 3.11, 3.12 or 3.13 all work. Do not use 3.14: scikit-learn 1.6.1 and
# numpy 2.1.3 publish no cp314 wheels. On Streamlit Community Cloud set the
